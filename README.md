📲 WhatsApp Ordering

The website uses WhatsApp Click-to-Chat for order submission.

Customer selects products → adds them to the cart → reviews the total → clicks WhatsApp-la Sifarişi Göndər.

A dynamic message is automatically generated based on the current cart.

Example:

Yeni sifariş
Toyuq dönəri x2 — 4.60 AZN
Kartof fri x1 — 2.50 AZN
Lülə lavaşda x1 — 3.50 AZN
Cəmi: 10.60 AZN
Məhsullarınızı seçdiniz!
İndi bu mesajı göndərin və öz ev ünvanınızı və ya konumunuzu bizə WhatsApp vasitəsilə göndərin.
Ünvan / Konum:
Müştəri WhatsApp-da göndərəcək.

The customer then sends their address or location directly through WhatsApp.
